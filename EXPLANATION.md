# Пояснение к коду (Technical Explanation)

## 1. Архитектура Проекта (Architecture)

Проект построен на **MVC (Model-View-Controller)** архитектуре, адаптированной для REST API.
В данной реализации "View" (Вид) — это клиентская часть (React), которая будет общаться с сервером через JSON, поэтому сервер фактически реализует архитектуру **MC (Model-Controller)** с маршрутизацией.

### Структура папок (Folder Structure)

```
project-root/
├── src/
│   ├── config/       # Конфигурационные файлы (подключение к БД)
│   ├── controllers/  # Логика обработки запросов (бизнес-логика)
│   ├── models/       # Схемы данных Mongoose (описание сущностей)
│   ├── routes/       # Определение маршрутов (endpoints) API
│   ├── middleware/   # Промежуточное ПО (auth, валидация, логирование)
│   ├── utils/        # Вспомогательные функции
│   └── app.js        # Настройка Express приложения
├── server.js         # Точка входа в сервер
├── .env              # Переменные окружения (секретные ключи, доступы)
└── package.json      # Зависимости проекта
```

### Назначение ключевых файлов

- **server.js**: Инициализирует запуск сервера. Это точка входа, которая поднимает HTTP-сервер и подключает базу данных.
- **src/app.js**: Конфигурирует Express приложение. Здесь подключаются глобальные middleware (CORS, Helmet для безопасности, разбор JSON) и определяются основные маршруты.
- **src/config/db.js**: Отвечает за соединение с MongoDB. Использует библиотеку `mongoose` для асинхронного подключения.

## 2. База Данных (Database)

Мы используем **MongoDB** — документоориентированную NoSQL базу данных.
Для взаимодействия с ней используется ODM (Object Data Modeling) библиотека **Mongoose**.

Mongoose позволяет нам описывать строгие схемы данных (Schema), валидировать данные перед сохранением и удобно взаимодействовать с базой через объекты (Models).
